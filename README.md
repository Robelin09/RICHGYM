# Progreso Gym

PWA para registrar peso, repeticiones y rutinas por grupo muscular. Los datos se almacenan localmente en el navegador.

## Probarla en tu computadora

Desde esta carpeta ejecuta:

```powershell
python -m http.server 8080
```

Después abre `http://localhost:8080`.

## Instalarla en iPhone

Publícala en un hosting con HTTPS (por ejemplo, GitHub Pages, Netlify o Vercel), abre la URL en Safari y usa **Compartir → Añadir a pantalla de inicio**. Así se instalará como app.

Los datos de entrenamiento quedan en el iPhone. Usa **Historial → Exportar** para guardar una copia JSON.
